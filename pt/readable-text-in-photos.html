Texto legível numa foto

Uma etiqueta num produto, uma placa, uma página de documento ou uma captura de ecrã costumam esborratar as letras ao ampliar. O EasyUpscale AI tem o seu próprio modelo de texto, treinado de raiz para letras, etiquetas e documentos.

Transferir grátis para Windows · Comprar uma licença · 14,99 €

Como fazer

  • Uma página de texto. O modo Auto reconhece uma imagem que é mesmo texto (papel claro, tinta fina e escura em linhas) e usa o modelo de texto.
  • Texto numa foto. Numa foto normal, o Auto encontra as partes com texto (uma etiqueta, uma placa, uma folha sobre a mesa) e amplia só essas com o modelo de texto. O resto passa pelo modelo de fotos e as margens fundem-se suavemente.
  • À mão. No modo Avançado (com licença) pode escolher o modelo de texto para uma imagem inteira.

Com honestidade

  • A deteção do que é texto é propositadamente rigorosa: encontra cerca de três quartos de uma etiqueta e nada em fotos sem texto. Uma palavra que escape é simplesmente ampliada pelo modelo de fotos.
  • O modelo amplia, não lê (não é OCR). Texto muito desfocado continua ilegível.
  • O modelo é treinado apenas com dados que podem ser usados comercialmente (veja Sobre).

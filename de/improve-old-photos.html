Alte Fotos verbessern

Alte Fotos, Scans und Handyaufnahmen von früher sind oft klein, körnig oder durch Kompression beschädigt. EasyUpscale AI vergrößert sie, entfernt das Rauschen und schärft sie.

Kostenlos für Windows herunterladen · Lizenz kaufen · 14,99 €

So geht's

  1. Scannen oder fotografieren Sie das Original und öffnen Sie die Datei in EasyUpscale AI.
  2. Der Auto-Modus erkennt eine beschädigte oder verrauschte Aufnahme und wählt ein Restaurierungsmodell. Im erweiterten Modus (mit Lizenz) können Sie das Modell SwinIR realSR wählen, gemacht für alte, verrauschte und JPEG-beschädigte Fotos.
  3. Ein verrauschtes Foto wird zuerst gesäubert, danach wird feines Korn zurückgegeben, damit das Ergebnis nicht wie gemalt wirkt.

Ehrlich gesagt

  • Das Ergebnis ist eine Verbesserung, keine originalgetreue Rekonstruktion. KI kann fehlende Teile von Gesichtern und Details nicht zuverlässig ergänzen.
  • Die Vergrößerung auf 2× ist kostenlos, 4× erfordert eine Lizenz (14,99 €, einmalig).
  • Ihr Original wird nicht überschrieben; Sie speichern das Ergebnis als neue Datei.

Datenschutz

Familienfotos bleiben auf Ihrem Computer. Nichts wird hochgeladen.

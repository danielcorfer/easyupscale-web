Lesbarer Text im Foto

Ein Etikett auf einem Produkt, ein Schild, eine Dokumentseite oder ein Screenshot verschmiert beim Vergrößern oft die Buchstaben. EasyUpscale AI hat ein eigenes Textmodell, von Grund auf für Buchstaben, Etiketten und Dokumente trainiert.

Kostenlos für Windows herunterladen · Lizenz kaufen · 14,99 €

So geht's

  • Eine Textseite. Der Auto-Modus erkennt ein Bild, das wirklich Text ist (helles Papier, dünne dunkle Tinte in Zeilen), und nutzt das Textmodell.
  • Text im Foto. In einem normalen Foto findet Auto die Stellen mit Text (ein Etikett, ein Schild, ein Blatt auf dem Tisch) und vergrößert nur diese mit dem Textmodell. Der Rest läuft durch das Fotomodell, die Ränder werden weich überblendet.
  • Von Hand. Im erweiterten Modus (mit Lizenz) können Sie das Textmodell für ein ganzes Bild wählen.

Ehrlich gesagt

  • Die Prüfung, was Text ist, ist absichtlich streng: Sie findet etwa drei Viertel eines Etiketts und in Fotos ohne Text nichts. Ein übersehenes Wort wird einfach vom Fotomodell vergrößert.
  • Das Modell vergrößert, es liest nicht (es ist keine OCR). Stark verschwommener Text bleibt unleserlich.
  • Das Modell wurde nur mit Daten trainiert, die kommerziell genutzt werden dürfen (siehe Über das Projekt).

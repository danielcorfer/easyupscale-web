Ein kleines Bild für den Druck

Ein Bild aus dem Web oder ein älteres Foto hat oft nicht genug Pixel für den Druck. EasyUpscale AI vergrößert es, damit es auch in größerem Format besteht.

Kostenlos für Windows herunterladen · Lizenz kaufen · 8,99 €

Schritte

  1. Öffnen Sie das Bild.
  2. Wählen Sie im erweiterten Modus (mit Lizenz) eine Größe: 2×, 4× oder eine Zielauflösung wie 4K oder Full HD. Ohne Lizenz können Sie 2× vergrößern.
  3. Speichern Sie als PNG, JPEG, WebP, AVIF, TIFF oder BMP (die kostenlose Version speichert PNG und JPEG). Transparenz und Metadaten bleiben erhalten.

Gut zu wissen

  • Für den Druck braucht man meist etwa 300 Pixel pro Zoll: A4 sind ungefähr 2480 × 3508 px. Rechnen Sie vorher aus, wie viel Vergrößerung Sie brauchen.
  • Das Vergrößern ergänzt glaubhafte Details, macht aus einem extrem kleinen Bild aber kein scharfes großes Foto.
  • Stapel und ein überwachter Ordner (mit Lizenz) sparen Klicks, wenn Sie viele Bilder auf einmal vergrößern.

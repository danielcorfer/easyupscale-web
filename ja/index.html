よくある質問

画像はサーバーにアップロードされますか？

いいえ。計算はお使いのブラウザー上、お使いのグラフィックスカードで行われます。サーバーからダウンロードされるのはモデルだけです。

デモは本当に無料ですか？

はい、2 倍拡大は無料で、結果の隅に小さな透かしが入ります。透かしなしの結果は 1 枚あたり €1.49 で、ライセンスキーなら恒久的に消えます。Windows アプリは 2 倍なら無料で透かしなし、ライセンスで 4 倍拡大が使えます。

どのブラウザーが一番よく動きますか？

WebGPU に対応した最新の Chrome または Edge です。WebGPU がない場合は計算がプロセッサで行われ、かなり遅くなります。

なぜアプリのほうが速いのですか？

アプリはブラウザーの制限なしにグラフィックスカードを直接使います。RTX 4060 での当社の測定では約 2～3 倍高速でした。結果はパソコンによって異なります。

画像が大きい場合は？

アプリは最大 120 Mpx の結果を扱えます。ブラウザーでは大きな画像がメモリの上限に達することがあるため、大きな画像にはアプリが向いています。

Windows 以外でも動きますか？

Web デモは、十分に対応したブラウザーならどれでも動きます。フルアプリは Windows 専用です。

ライセンスを買った後で気が変わったら？

14 日以内であれば返金を受けられます。

ライセンスはインターネットなしで動きますか？

拡大処理はオフラインで動作します。ライセンスキーはオンラインで認証され、アプリは起動時に確認します。インターネットがなくてもライセンスは 7 日間有効で、その後は接続が必要です。

アプリの動作環境は？

Windows 10（バージョン 1903 以降）または Windows 11（64 ビット）、DirectX 12 対応のグラフィックスカード、約 1 GB のディスク空き容量、推奨メモリ 8 GB。

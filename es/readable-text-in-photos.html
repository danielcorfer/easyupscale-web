Texto legible en una foto

Una etiqueta de un producto, un cartel, una página de un documento o una captura de pantalla suelen emborronar las letras al ampliarlas. EasyUpscale AI tiene su propio modelo de texto, entrenado desde cero para letras, etiquetas y documentos.

Descargar gratis para Windows · Comprar una licencia · 14,99 €

Cómo hacerlo

  • Una página de texto. El modo Auto reconoce una imagen que realmente es texto (papel claro, tinta fina y oscura en líneas) y usa el modelo de texto.
  • Texto dentro de una foto. En una foto normal, Auto localiza las partes con texto (una etiqueta, un cartel, una hoja sobre la mesa) y amplía solo esas con el modelo de texto. El resto pasa por el modelo de fotos y los bordes se funden suavemente.
  • A mano. En el modo Avanzado (con licencia) puedes elegir el modelo de texto para una imagen entera.

Con honestidad

  • La detección de qué es texto es estricta a propósito: encuentra aproximadamente tres cuartos de una etiqueta y nada en fotos sin texto. Una palabra que se escape la amplía simplemente el modelo de fotos.
  • El modelo amplía, no lee (no es OCR). El texto muy borroso sigue siendo ilegible.
  • El modelo está entrenado solo con datos que pueden usarse comercialmente (consulta Acerca de).

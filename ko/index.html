자주 묻는 질문

내 이미지가 서버에 업로드되나요?

아니요. 계산은 브라우저에서 그래픽 카드로 실행됩니다. 서버에서는 모델만 내려받습니다.

데모는 정말 무료인가요?

네, 2배 확대는 무료이며 결과물 모서리에 작은 워터마크가 들어갑니다. 워터마크 없는 결과는 이미지당 €1.49이고, 라이선스 키를 쓰면 계속 제거됩니다. Windows 앱은 2배까지 무료이며 워터마크가 없고, 라이선스로 4배 확대를 사용할 수 있습니다.

어떤 브라우저에서 가장 잘 동작하나요?

WebGPU를 지원하는 최신 Chrome 또는 Edge입니다. WebGPU가 없으면 프로세서에서 계산하며 눈에 띄게 느립니다.

앱이 왜 더 빠른가요?

앱은 브라우저의 제약 없이 그래픽 카드를 직접 사용합니다. RTX 4060에서의 자체 측정으로 약 2~3배 빨랐으며, 결과는 컴퓨터마다 다릅니다.

이미지가 크면 어떻게 되나요?

앱은 최대 120 Mpx 결과까지 처리합니다. 브라우저에서는 큰 이미지가 메모리 한계에 부딪힐 수 있어, 큰 이미지에는 앱이 더 적합합니다.

Windows가 아닌 시스템에서도 동작하나요?

웹 데모는 충분히 지원하는 모든 브라우저에서 동작합니다. 전체 앱은 Windows 전용입니다.

라이선스를 구매한 뒤 마음이 바뀌면요?

14일 이내에 환불받을 수 있습니다.

라이선스는 인터넷 없이 동작하나요?

확대 처리는 오프라인으로 동작합니다. 라이선스 키는 온라인으로 활성화되고 앱이 시작될 때 확인합니다. 인터넷이 없어도 라이선스는 7일간 유효하며, 그 후에는 연결이 필요합니다.

앱의 시스템 요구 사항은 무엇인가요?

Windows 10(버전 1903 이상) 또는 Windows 11(64비트), DirectX 12를 지원하는 그래픽 카드, 약 1 GB의 디스크 공간, 권장 메모리 8 GB.

웹 데모는 이미지를 사용자의 기기에서 처리합니다. 아무것도 업로드되지 않습니다.

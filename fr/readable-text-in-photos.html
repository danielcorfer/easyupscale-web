Un texte lisible dans une photo

Une étiquette sur un produit, un panneau, une page de document ou une capture d'écran brouillent souvent les lettres à l'agrandissement. EasyUpscale AI a son propre modèle de texte, entraîné de zéro pour les lettres, les étiquettes et les documents.

Télécharger gratuitement pour Windows · Acheter une licence · 8,99 €

Comment faire

  • Une page de texte. Le mode Auto reconnaît une image qui est vraiment du texte (papier clair, encre fine et sombre en lignes) et utilise le modèle de texte.
  • Du texte dans une photo. Dans une photo ordinaire, Auto repère les zones de texte (une étiquette, un panneau, une feuille sur une table) et n'agrandit qu'elles avec le modèle de texte. Le reste passe par le modèle photo et les bords se fondent en douceur.
  • À la main. En mode Avancé (avec licence), vous pouvez choisir le modèle de texte pour toute une image.

En toute honnêteté

  • La détection du texte est volontairement stricte : elle trouve environ les trois quarts d'une étiquette et rien dans les photos sans texte. Un mot manqué est simplement agrandi par le modèle photo.
  • Le modèle agrandit, il ne lit pas (ce n'est pas de l'OCR). Un texte très flou reste illisible.
  • Le modèle est entraîné uniquement sur des données utilisables commercialement (voir À propos).

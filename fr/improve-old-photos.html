Améliorer de vieilles photos

Les vieilles photos, les scans et les clichés de téléphone d'il y a des années sont souvent petits, granuleux ou abîmés par la compression. EasyUpscale AI les agrandit, nettoie le bruit et les affine.

Télécharger gratuitement pour Windows · Acheter une licence · 14,99 €

Comment faire

  1. Numérisez ou photographiez l'original et ouvrez le fichier dans EasyUpscale AI.
  2. Le mode Auto reconnaît une image abîmée ou bruitée et choisit un modèle de restauration. En mode Avancé (avec licence), vous pouvez choisir le modèle SwinIR realSR, conçu pour les photos anciennes, bruitées et abîmées par le JPEG.
  3. Une photo bruitée est d'abord nettoyée, puis du grain fin est remis, pour que le résultat ne paraisse pas peint.

En toute honnêteté

  • Le résultat est une amélioration, pas une reconstruction fidèle. L'IA ne peut pas combler de façon fiable les parties manquantes de visages ou de détails.
  • L'agrandissement 2× est gratuit, le 4× nécessite une licence (14,99 €, en une fois).
  • Votre original n'est pas écrasé ; vous enregistrez le résultat dans un nouveau fichier.

Confidentialité

Les photos de famille restent sur votre ordinateur. Rien n'est envoyé.
